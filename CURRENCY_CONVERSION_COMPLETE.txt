CURRENCY CONVERSION IMPLEMENTATION - COMPLETE
=============================================

## Summary of Changes:

### Customer Ledger & Supplier Ledger

Both ledgers now have complete currency conversion functionality:

1. **Opening Balance Conversion**
   - Customer/Supplier opening_debit_amount and opening_credit_amount are converted from base currency to target currency
   - Sub-account opening balances are also converted

2. **Transaction Conversion**
   - All transactions (invoices, payments, returns, PDCs, rent) are converted based on their currency_id
   - PDCs get currency_id via JOIN with payment_voucher/receive_voucher
   - Accounting ledger gets currency_id via JOIN with rent_management

3. **Frontend Updates**
   - Currency dropdown added to filters
   - Currency symbol updates dynamically (currentCurrencySymbol variable)
   - All amounts display in selected currency
   - Print function includes currency_id parameter

4. **API Endpoints**
   - Added /currencies endpoint to load tenant currencies
   - Added currency_id parameter to all ledger queries
   - Currency converter class handles all conversions using ExchangeRate API

## Key Features:

✓ Live exchange rate conversion
✓ Opening balance conversion
✓ Transaction-level currency conversion
✓ Sub-account support
✓ Print with selected currency
✓ No database migration required
✓ Handles null currency IDs gracefully
✓ Caches exchange rates for performance
